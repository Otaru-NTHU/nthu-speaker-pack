# 清華講座單據包

邀請校外講者到國立清華大學演講時，讓講者填一次基本資料，就產出核銷需要的整包單據：

- 教發中心（教師創新教學／跨域富學社群／共學圈圈）：支出憑證黏存單＋印領清冊（講座鐘點費、交通費）
- 通用（系所／學校）：國立清華大學領據（演講費、交通費）
- 校外人士匯款同意書
- 加浮水印的身分證正反面與存摺影本

## 使用方式

1. 邀請人填「經費來源與活動資料」，按「產生講者連結」，把連結傳給講者（連結只含活動資料）。
2. 講者打開連結，填個人資料、帳戶、交通資訊，上傳存摺與身分證。
3. 下載 PDF，印出後在簽名欄親筆簽名，正本交給邀請人（學校不收電子簽章）。

所有資料只在瀏覽器內處理，不會上傳到任何伺服器。

表單版式依教學發展中心 115-1 核銷說明與學校通用表單重製，送件前請以承辦單位最新規定為準。
